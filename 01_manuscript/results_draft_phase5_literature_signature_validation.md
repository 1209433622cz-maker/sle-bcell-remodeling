# Results Draft - Phase 5 Literature-Informed Signature Validation

## Literature-Informed Signatures Validate The ABC/APC-Like Identity Of The Central SLE-Associated State

To determine whether the central ABC/APC-like state aligned with external biological concepts from the SLE B-cell literature, we evaluated a panel of literature-informed marker signatures using donor-state pseudobulk expression. The signature panel included ABC/DN2 core markers, an ABC-low-naive-context signature, a ZEB2-linked ABC axis, APC/HLA B-cell markers, an EBV/APC-like B-cell signature, IFN/ISG markers, a TLR7/FTO innate-axis signature, an age-associated/atypical B-cell signature, and control signatures for naive B cells, memory B cells, plasmablasts/ASCs, and platelet/ambient RNA.

The atypical ABC/APC-like state ranked first among refined B-cell states for ABC/DN2 core, ABC-low-naive-context, ZEB2-linked ABC, APC/HLA B-cell, EBV/APC-like B-cell, and age-associated/atypical B-cell signatures. In donor-state comparisons, the strongest focus-state effects were observed for the age-associated/atypical B-cell signature (delta 0.939; FDR 1.28e-87), ABC-low-naive-context signature (delta 0.859; FDR 6.04e-85), ZEB2-linked ABC signature (delta 0.694; FDR 7.76e-93), ABC/DN2 core signature (delta 0.448; FDR 1.56e-92), APC/HLA B-cell signature (delta 0.413; FDR 2.63e-83), and EBV/APC-like B-cell signature (delta 0.259; FDR 7.13e-71).

The focus state also showed modest IFN/ISG enrichment (delta 0.076; FDR 1.90e-06), but this signature was not uniquely maximal in the ABC/APC-like state. The TLR7/FTO innate-axis signature was not specifically elevated in the focus state (delta -0.002; FDR 0.447), indicating that TLR7/FTO biology should be discussed as broader mechanistic context rather than as a state-defining feature in this dataset.

Control signatures supported the specificity of the annotation. The ABC/APC-like state did not rank as a naive B-cell or plasmablast/ASC endpoint, and the platelet/ambient-RNA signature was highest in the flagged platelet/ambient-high cluster rather than in the ABC/APC-like state.

## Working Manuscript Claim

The literature-informed signature analysis strengthens the central interpretation that the SLE-expanded focus state is an atypical ABC/APC-like B-cell population. It links the state to ABC/DN2, ZEB2-associated, antigen-presentation, EBV/APC-like, and age-associated/atypical B-cell biology while preserving a clear boundary around TLR7/FTO claims.

## Limitations To Preserve

- The signature panel is literature-informed and marker-based; final manuscript use requires formal citation audit.
- Signature validation supports biological interpretation but does not provide independent dataset replication.
- TLR7/FTO should not be presented as a focus-state-specific result based on the current analysis.
