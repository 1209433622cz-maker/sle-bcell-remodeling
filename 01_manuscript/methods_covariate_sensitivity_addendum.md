# Methods Addendum - Covariate Sensitivity

Donor-level covariate sensitivity analysis used the B-lineage donor fraction table and donor metadata from the B-lineage H5AD object. Age was parsed from the CELLxGENE `development_stage` field. Donor-level metadata included disease status, disease state, sex, self-reported ethnicity, processing cohort, and donor B-lineage cell count. Donors with cells represented across multiple processing cohorts were assigned to a `multiple` processing cohort category for donor-level modeling. Donors with multiple SLE disease-state labels were assigned to an `SLE mixed` category for descriptive disease-state summaries.

For each refined B-cell state, donor-level fractions were modeled using ordinary least squares with HC3 robust standard errors. Three model specifications were evaluated: an unadjusted disease-only model; a demographic model adjusted for disease status, age, sex, and self-reported ethnicity; and a full model adjusted for disease status, age, sex, self-reported ethnicity, simplified processing cohort, and log10 donor B-lineage cell count. Disease coefficients represent the estimated difference in donor-level state fraction for SLE donors compared with normal donors. Benjamini-Hochberg correction was applied across B-cell states within each model specification.
