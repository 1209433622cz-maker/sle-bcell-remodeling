# SLE B-cell remodeling analysis public release

This is the author-approved reproducible release supporting the manuscript:

> Disease-blind single-cell reconstruction separates unstable B-cell states from reproducible interferon remodeling in systemic lupus erythematosus

## Release contents

- Versioned analysis and audit code for the disease-blind single-cell workflow.
- Five publication main figures and seven supplementary figures.
- Machine-readable source data for all main figures.
- Complete gene-level statistical results, sanitized design matrices and regulator-sensitivity outputs.
- Final manuscript, supplementary information, cover letter and portal upload maps.
- Environment records, machine-readable decisions and SHA-256 integrity manifests.

## Scientific scope

The release supports a broad conventional-B identity scope, sample-level composition analysis, within-compartment IFN/ISG transcription, independent external validation and prespecified regulatory and perturbational evidence. The findings are observational and do not establish a discrete B-cell subtype, causal regulator, unique upstream stimulus or treatment benefit.
