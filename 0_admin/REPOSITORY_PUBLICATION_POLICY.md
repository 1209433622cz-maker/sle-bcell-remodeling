# Repository Publication Policy

Date: 2026-10-12. This update restructures navigation and publishes bounded
scientific-review candidates in the existing public repository. It does not
delete/recreate the repository or replace immutable releases.

## Included

- Eight main folders with usable scientific entry points and explicit READMEs.
- Preserved manuscript baseline, separately labelled review candidates,
  canonical figures and compact figure/source-data tables.
- Panel/claim/edition matrices, compact numerical/visual/accessibility QA and
  the original audit findings, including the failed Skill package check.
- Original project build/verification code and a standard-library verifier.
- Historical HOLD decisions, recovery records and navigation.

## Excluded from This Update

- Large matrices, raw reads and full Monte Carlo checkpoint trees.
- The third-party QiTeng Skill distribution and its runtime.
- Full machine-local path/duplicate inventories, rendered page caches,
  received-baseline exports and duplicated proof PDFs.
- Credentials, tokens, local account state and private configuration.

Excluding the Skill distribution does not hide its failed package QA or imply
certification. Compact raw reports and limitations are published separately.

## Scientific State

Publishing a candidate is not author approval. Existing package files do not
contain it unless an explicit future build says so. Stage I/WP1 are the same
68-donor estimand; GSE262846 has no current expression outcome.

## Integrity Scopes

`PUBLIC_ASSET_MANIFEST.csv` binds selected scientific/navigation assets, not
every historical object. `PUBLIC_REPOSITORY_INDEX.csv` inventories Git-tracked
paths, sizes and hashes at publication preparation. Generated index, manifest
and verification receipts are excluded from self-referential hashing.

The verifier checks the curated manifest, critical copies, scientific state and
selected Markdown links. The 41,249-file local snapshot includes ignored
evidence and is not the upload count. No scientific-path migration occurs.
