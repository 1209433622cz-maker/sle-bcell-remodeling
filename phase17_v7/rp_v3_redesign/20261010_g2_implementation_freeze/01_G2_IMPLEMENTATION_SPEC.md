## New generative assumptions, not historical facts

1. Use the joint 68-donor by five-bin sufficient-count templates, selected by the already frozen WP1 support IDs. Strip donor identifiers and actual disease labels from the model object. A whole template (all bins, genes, n and captured-library size) is drawn uniformly, independently of the simulated arm and design row. This retains empirical joint template heterogeneity/correlation; it does not claim to estimate the true biological covariance, reproduce clinical confounding, or generate a new cohort.
2. Model 13 Poisson categories: the 12 program genes and the sum of all remaining genes. The remainder is L minus the sum of the 12 counts, never omitted from the denominator. For calibration only, use the Dirichlet posterior-mean probabilities (C+0.5)/(L+13*0.5), including the remainder. This explicitly specified simulation regularizer is NOT added to real counts and does not replace the inherited T0 +0.5. Empirical-zero template genes are not forced to be structural zero.
3. A common-support core generator draws n=30+Multinomial(N-150,w). Weights w are proportional to (n_template-30+1)*exp(D*composition_log_tilt*a), a=(-1,-0.5,0,0.5,1). The 30-cell reserve defines the simulation's conditional core domain; it is not estimator-side padding or rescue. There is no replacement of failed simulations. It also means the core law is conditional on common support, NOT an unconditional cellular-sampling law for the entire accession. In R1, after the core draw, bin-1 cells are binomial-thinned with the registered .35 multiplier and transferred to bin 5, so support can genuinely fail.
4. Synthetic within-bin log2fc is applied to the IFN12 category rates in every bin. Captured UMI/cell starts from the joint donor template. R2 halves all case capture rates; R4 multiplies case bin rates by exp(0.4*a). The same factors affect the remaining background. Thus measured program truth is not assumed to equal the injected log2fc and nominal C0 may have nonzero measured truth under arm-specific depth/capture.
5. In R3 each true-bin cell moves with probability .15 to an adjacent bin (interior directions .5/.5; boundary only neighbor). n flows are multinomial. Conditional on flows, each gene/background category count is Poisson with rate flow-cell-count times source-bin capture times source-gene relative rate. Summing flows by observed bin exactly preserves totals. The sufficient-count law is equivalent to sums of conditionally Poisson cell-category counts with constant template-bin rates. It does NOT model cell-level expression-dependent misclassification or overdispersion beyond template mixture and Poisson sampling.
6. All 68 generated donors must have observed n>=30 in every bin and L>0. If not, the whole replicate is SUPPORT_STOP; no donor dropping, redrawing, merging, zero filling or adaptive pi renormalization. R1 is expected to expose an applicability boundary, not a success case to be rescued.
7. Frozen X is used for estimation. Template draws are independent of X, so conditional on whole-replicate support E[S|X]=mu_0 + D*(mu_1-mu_0). Population truth of the D coefficient is mu_1-mu_0 under the corresponding observed-support conditional distribution. Each target includes the nonlinear transform AFTER observed counts and full denominators. This is an observed-measurement target, NOT oracle latent-cell-state recovery.
8. C3/C4 names encode the registered parameter signs only. With empirical bin profiles, the observed-score composition contrast need not have the same sign as the log-tilt. No tilt is reversed to obtain desired cancellation or reinforcement. This meaning must be reviewed before full execution; pilot values do not rewrite the registry.

## Independent truth implementation

The truth engine imports neither the generator nor the estimation/scoring module. It implements the category rate and observation equations independently, samples using a different NumPy bit generator, integrates each template with equal effort, and computes conditional means rather than fitting the method under evaluation. It may share immutable model parameters, never generated estimator results. Conditional Poisson superposition permits a different implementation: sum cell-flow rates to observed-bin rates, then draw Poisson counts. Both arms use a common-minimum Poisson coupling, retaining correct marginal laws and reducing Monte Carlo error.

Truth begins with 16 independent batches x 64 draws per template per arm; doubles per-template effort up to 1024 per batch if precision is insufficient. Stage sizes 64,128,256,512,1024 are fixed before execution. Inspect all targets; stop only on precision, not effect direction. At the cap retain HOLD_TRUTH_PRECISION. The receipt reports batch MCSE, analytic zero when symmetry proves it, and a covariance-aware typical coefficient SE using fixed-design leverage and the simulated donor-score variance. Matching the inherited rule requires MCSE <= 1% of that SE. A 1.96*MCSE uncertainty envelope is additionally reported, not silently substituted for the registered metric. No unstratified/pooled truth is substituted for conditional-support truth.

C0_R0/C0_R1/C0_R3 have identical synthetic-arm laws and are analytic zero for each implemented target. Other cells are NOT declared true-null from their scenario name or from a small numerical estimate.

These 50 attempts are NONADJUDICATIVE technical runs, not a shortened full G2. Also include deliberately unsupported, zero-background and rank-deficient fixtures. Pilot streams use a dedicated stage key; no pilot random stream is reused by full G2 or truth.

Counter-addressable SeedSequence keys contain stage/scenario/attempt/component. Seeds inherited: outer=2026101002; truth=2026101003. Every attempt, support stop and numerical failure is persisted. No failed-attempt replenishment. Fixed pi/T0/mapping/cutpoints and support are not relearned inside donor bootstrap. Weighted bootstrap OLS solves the exact expanded-row resample algebra; its equivalence to direct expanded-row least squares is independently tested. No HC3 replacement.

Checkpoint keys bind code+input+model hashes. Valid existing attempts are checked and reused, never overwritten. Altered inputs, partial/orphan payloads, altered code or missing attempt IDs fail closed. Full-run approval cannot be inferred from populated hashes alone, and the runner in this package is pilot-only. Windows runtime qualification remains separate from Linux pilot results.
