# QiTeng Manuscript Surface Convention Engine v1.0

Compatible core: `QiTeng Academic Writing Skill v0.3.20`

Calibration:
`SECOND DIRECT TENG QI FEEDBACK + LONGITUDINAL SCN FORMAT EVIDENCE + CURRENT JOURNAL AUTHORITY CHECK`

## 1. Surface is an independent editorial layer

Scientific logic can be correct while the manuscript still feels wrong because:
- paragraph geometry is unfamiliar;
- citation punctuation conflicts with author habit;
- legends carry evidence-management clutter;
- Conclusion behaves like another Discussion paragraph;
- abbreviations are introduced inconsistently.

Hard:

> **ARGUMENT QUALITY != MANUSCRIPT SURFACE QUALITY.**

## 2. Teng-Qi house paragraph model

For AUTHOR_REVIEW / LAB_HOUSE copies when the author wants Teng-Qi house style:

`BLOCK STYLE`
- no first-line indent;
- one blank line between prose paragraphs;
- fully justified body text;
- headings remain left aligned.

Longitudinal evidence:
- SCN 0602 audited body paragraphs: 100% justified, 0 first-line indent, 100% blank-line separation;
- SCN 0716 audited body paragraphs: 100% justified, 0 first-line indent, ~98% blank-line separation.

Hard:

> **PARAGRAPH GEOMETRY IS A FORMAT CONTRACT, NOT A LANGUAGE PREFERENCE.**

## 3. Citation-surface authority

Teng-Qi house/review preference:
`[1]`, `[2–4]`.

But house citation punctuation is not universal journal law.

For a TARGET_JOURNAL_SUBMISSION:
`CURRENT OFFICIAL JOURNAL STYLE > HOUSE CITATION STYLE`.

Current Frontiers Vancouver guidance uses Arabic numerals in parentheses; square brackets are specified for physics/mathematics articles.

Therefore:
- author/Teng-Qi review copy may use square brackets;
- Frontiers submission interface must be converted to the active Frontiers style.

Hard:

> **CITATION IDENTITY IS CONTENT; CITATION PUNCTUATION IS INTERFACE.**

## 4. Figure legend citation gate

Teng-Qi default:
`CITATION-FREE LEGEND`.

A figure legend should explain:
- what the figure shows;
- panel logic;
- necessary symbols/abbreviations;
- essential interpretive boundary.

Do not append a mini bibliography to the legend when supporting literature is already owned by the main text.

Exceptions:
- reproduced/adapted/modified external material requiring attribution;
- rights-holder instructions;
- explicit journal rule;
- a genuinely necessary source that cannot be owned elsewhere.

## 5. Conclusion citation gate

Teng-Qi default:
`REFERENCE-FREE CONCLUSION`.

Conclusion should:
`SYNTHESIZE -> PRIORITIZE -> STATE BOUNDARY -> END`.

Do not:
- re-list evidence citations;
- introduce a new study;
- reopen literature debate;
- create a final mini-Discussion.

Cross-corpus calibration:
13/13 detected QiTeng-corpus Conclusion sections contained no numeric citation groups.

Hard:

> **CONCLUSION = ADJUDICATED SYNTHESIS, NOT EVIDENCE RE-LITIGATION.**

## 6. Abbreviation lifecycle

For ordinary/non-standard abbreviations:
`FULL TERM (ABBR)` at first main-text use.

Maintain an end-list when required by author/project/journal.
For the current project:
alphabetized list before Acknowledgments.

Do not conflate:
- prose abbreviations;
- official gene/protein symbols;
- units.

## 7. Interface copies

One content master may generate:
- TENG_QI_HOUSE_REVIEW_COPY
- TARGET_JOURNAL_SUBMISSION_COPY

They may differ in:
- citation brackets/parentheses;
- paragraph spacing;
- line/page numbering;
- figure placement;
- reference formatting.

They must not differ silently in scientific claims.

Core formula:

> **FREEZE SCIENCE ONCE; COMPILE THE CORRECT SURFACE FOR THE CORRECT READER/AUTHORITY.**
