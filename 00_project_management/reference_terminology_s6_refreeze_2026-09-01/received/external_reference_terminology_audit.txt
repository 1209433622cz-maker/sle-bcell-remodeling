### 1. 32 篇参考文献：主体 claim-support 关系是稳的

我逐条把正文实际引用的句子反向映射到 32 篇参考文献，并优先用 PubMed、NCBI GEO、Bioconductor/原始方法论文核对，而不是仅凭题名判断。

生物学背景引用目前没有发现 central claim 被文献“托不住”的情况。例如，Banchereau 的原始研究确实将 plasmablast signature 与 pediatric SLE disease activity 联系起来；Chiche 确实报告了不同 IFN modules 的 activation thresholds；van Dooren 确实描述了高 disease activity、Sm/RNP autoantibodies 与较高 plasmablast/memory ratio 的亚群；Sayadi 也明确支持 antimalarial treatment/low disease activity 下持续 IFN signaling 并伴随 polygenic-risk 差异。([PubMed][1])

“几类 interferon 都具有促进 B-cell activation/differentiation 的能力”这一句也成立：IFN-α、IFN-λ 和 type-I IFN/DN2 三组实验文献分别提供了对应支持。([PubMed][2]) 因此这里**不应该为了增加引用数量继续扩充 Introduction/Discussion**。

方法文献绝大部分同样准确。Scanpy、Harmony、Leiden、voom、CAMERA、CollecTRI/decoupleR 的引用和使用语义都成立。([PubMed][3])

三个需要处理的 reference-level 点是：

**Ref. 24 edgeR：建议补一个真正对应当前 pipeline 的方法引用。** 当前 Methods 写的是 `filterByExpr + TMM + robust quasi-likelihood`，而 Ref. 24 是 2010 年最初的 edgeR package paper。它当然支持“使用 edgeR”本身，但并不是这整套后续 quasi-likelihood workflow 最精确的 citation。当前句子见主文 Methods。 更准确的办法不是改分析，而是保留 Ref. 24，再新增 Chen, Lun & Smyth 2016 的 edgeR quasi-likelihood pipeline 作为 Ref. 33；该论文明确覆盖 RNA-seq filtering、normalization 和 edgeR QL workflow。([PubMed][4])

**Ref. 30 FRY：数据和方法没错，但一句话的 attribution 可以更严谨。** 当前写成 `FRY [30] provided a rotation-based directional test`。ROAST 原论文描述的是 rotation gene-set test；limma 文档更精确地定义 `fry` 为 `mroast` 的 fast approximation，而且可以给 directional result。([PubMed][5]) 所以我建议改成类似：

`FRY [27,30] provided a self-contained directional gene-set test as a fast approximation to the ROAST rotation framework.`

这样不会暗示 2010 ROAST paper 本身已经直接描述了后来 `fry()` 的全部实现。

**Ref. 31 是纯 bibliographic exactness 问题。** 当前写作：

`The Molecular Signatures Database Hallmark Gene Set Collection`

而原论文准确题名是：

`The Molecular Signatures Database (MSigDB) hallmark gene set collection.` ([PubMed][6])

这三项均不改变任何 scientific claim。

## 2. 术语锁还有几处应该统一

当前最大的 remaining inconsistency 是稿件已经建立了非常严格的 evidence vocabulary，但少数早期措辞还残留着旧层级。

我建议 source-level 统一：

* Abstract：`donor-aware inference` → **`biological-unit-aware inference`**。因为 GSE174188 的 primary unit 是 sample-cohort，而 GSE135779 才是 donor；当前 Methods 对这一点已经明确定义。
* `43 reference and 46 SLE strata` → **`43 control strata and 46 strata from source-defined managed SLE`**。
* `internal validation estimate/contrast` → **`internal replication estimate/contrast`**；同 accession 的证据不再正面称作 validation。
* `neither retained ... internal validation` → **`internal replication support`**。
* `GSE135779 served as the independent SLE validation dataset` → **`independent SLE replication dataset`**。
* Methods heading `Source-label-defined GSE135779 validation` → **`Source-label-defined GSE135779 replication`**。
* `source-metadata managed SLE / source-metadata flare` → **`source-defined managed SLE / source-defined flare`**。
* Discussion 的 `justify an IFN-centred regulatory interpretation` → **`support an IFN-centred regulatory context`**，与 Figure 5 的 observational ceiling 完全统一。
* Supplementary Table S1 的 `Discovery and internal validation` / `Independent SLE validation` → **internal replication / independent SLE replication**。
* Supplementary Table S5 的 `Independent GSE135779 validation` → **source-label-defined GSE135779 replication**。
* Supplementary S9 note 中残留的 `source-label-based` → **`source-label-defined`**。

值得强调的是，我**不建议全局删除 validation 一词**。例如“这些 calibration folds are not independent validation”以及 generic 的 reconstruction/validation 描述本身是正确的；CRediT 的 `Validation` 也必须保留。这里应该锁定 evidence-class 用语，而不是机械 search-and-replace。
