# 3. 新发现的第一个问题：Table S3 被挂到了错误的科学主张上

这是我认为本轮最值得修的一处。

当前 Results 结尾写成：

> `None of these analyses identifies a unique initiating ligand, establishes direct TF binding or demonstrates causal regulation in SLE (Supplementary Table S3).`



但 Supplementary Table S3 实际是什么？

**`Quantitative anchors and prespecified boundaries`**

里面放的是：

ARI/Jaccard、B_ASC OR、IFN effect、cross-dataset rho、M5911 NES、GSE23307 donor effects 等定量锚点。

它并不是“没有 causal regulator/direct binding”的 evidence owner。

而 GitHub anchor ledger 也明确证明这条 citation 是为了上一轮覆盖率人工加到这句话上的。

### 更准确的改法

把 S3 放到前面的 synthesis sentence：

> **Taken together, these layers support an IFN-centred interpretation of the replicated program while defining its evidential ceiling, with principal quantitative anchors summarized in Supplementary Table S3.**

然后后面的：

> `None of these analyses identifies ... causal regulation in SLE.`

**不挂 S3。**

这样 Table S3 真正拥有 quantitative summary，而 causal ceiling 仍由正文逻辑、Fig. 5 和 Table S2 支撑。

# 5. 第三处：Tables S5–S8 现在也挂错了句子

当前 Reproducibility 部分写：

> `Superseded manuscripts and figures were retained for provenance but were not used as numerical sources for the present version (Supplementary Tables S5-S8).`



但是 S5–S8 实际分别是：

* S5：selected figure source-data map
* S6：reproducibility record
* S7：statistical tests and multiplicity families
* S8：full statistical-results archive map。

它们并不直接证明“旧 manuscript 没有被当作 numerical source”。

所以 citation 应该移到上一句：

> **Analyses were organized in timestamped run directories with immutable source objects, deterministic seeds, environment records, machine-readable decisions and SHA-256 manifests (Supplementary Tables S5-S8).**

然后：

> `Superseded manuscripts and figures were retained for provenance but were not used as numerical sources for the present version.`

不挂表格。

这会比现在更自然，而且几乎不增加字数，因此大概率不会重新破坏 31 页双引擎一致性。
