## Objective

Convert the frozen Gate C7 scientific package into a complete, journal-ready
submission without changing the biological conclusions or reselecting analyses.

## Work order

1. Build a current two-lane journal shortlist: an ambitious upper-Q1 lane and a
   strong realistic Q1 lane, evaluated for scope, article type, public-data policy,
   word/figure limits and requirement for experimental validation.
2. Select one primary target and one fallback before journal-specific rewriting.
3. Verify every reference against primary publisher, PubMed or DOI metadata and
   produce the authoritative bibliography.
4. Collect author names, affiliations, contribution roles, corresponding-author
   details, funding, conflicts, ethics/data-reuse statements and acknowledgements.
5. Build the Extended Data/Supplementary architecture, source-data index, software
   and resource table, reporting checklist and reproducibility statement.
6. Tailor title, abstract, cover letter, significance language and manuscript length
   to the chosen journal while preserving the Gate C7 claim matrix.
7. Render and visually audit DOCX and PDF versions, including page flow, figure
   placement, legends, references, special characters and line numbering.
8. Assemble a checksum-verified submission directory and final preflight decision.

- Do not hide the low genome-wide correlation.

- Do not add a new dataset merely to increase dataset count; any new analysis must

## Required user-supplied metadata

Author order, complete affiliations, corresponding-author identity, funding,
conflicts of interest, contribution roles and acknowledgements will be required
before the submission package can be finalized. These items do not block the initial
journal shortlist, reference audit or supplement design.

## Gate C8 pass criterion

Pass only when the selected journal's technical requirements are met, every central
number and panel remains traceable to Gate C7, all author/declaration fields are
resolved, rendered documents pass visual QA, and the submission manifest contains no
superseded or local-only accidental files.
