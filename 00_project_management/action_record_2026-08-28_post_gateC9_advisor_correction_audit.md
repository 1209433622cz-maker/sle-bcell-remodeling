## 3. 严重问题与处置

### 3.1 阻断项：归一化不一致

旧代码先截取约 601 个参考特征，再除以这些特征的计数和；外部数据则先按
全转录组计数和归一化再截取特征。参考与外部模型输入不在同一预处理尺度上。
参考内部交叉验证无法检测这种跨数据集实现不一致。

修复为参考和外部均采用全库计数的 log1p(CP10K)，参考子集显式传入全库总数。
新增 `03_REFERENCE_LIBRARY_SIZE_AUDIT.csv` 记录每个参考训练细胞的全库计数、
特征计数、特征占比和旧版归一化放大因子。该因子是对数变换前的尺度差异，
不是疾病效应膨胀倍数。

### 3.2 阻断项：校准失败却被授权

旧弹性网诊断阈值 0.95 的 B_ASC 精确率为 **0.894074**，小于预设 **0.90**，
`eligible=False`。旧代码选择了 fallback，却只检查平均 balanced accuracy，
最终放行疾病结局。因而旧 PASS 的门控授权不成立，不能拿旧效应值继续增强手稿。

现在诊断 fallback 仍可记录，但没有授权功能；两种算法均须满足校准资格。
没有放宽阈值、扩大候选网格、换 seed、改变特征或挑选效果更好的算法。

### 3.3 潜在治理缺陷

- 结局命令行 metadata 未绑定到实际冻结的受保护输入。现检查路径和哈希。
- 缩小 `max-samples` 可让部分正式运行过关。现仅测试模式允许截断；正式运行
  要求 56 个样本、363,083 个细胞。
- 旧冻结只检查部分产物。现检查整个 prefreeze 清单并纳入执行脚本哈希。
- 旧重跑会删除同目录下的结局文件。现拒绝非空运行目录，保护冻结记录。

没有发现旧正式运行实际换过 metadata 或只跑了部分样本；这些是发现并修复的
潜在缺陷，不应描述成已发生的数据替换行为。

### 3.4 写作与推断边界

- RP 仍使用无条件“两大分群通过”，并将组成模型写作 conditional-binomial。
  已改为 frozen-representation pass 与 end-to-end HOLD 的区别及 beta-binomial。
- 两个映射器共享参考与特征，不能说成两份独立生物学验证。
- 特征筛选及超参数选择并非完整嵌套的外层留出验证；CV 数字只作为参考校准诊断。
- 参考训练子集富集了 B_ASC，精确率不等同于自然人群或外部细胞的预测精确率。
- 原 C9 计划将 Mann-Whitney 与既有外部主分析并列为“相同方法”，并不准确：
  既有主结果是标准化 pseudobulk 程序的 HC3 模型；C9 预定比较的是供体平均
  单细胞 logCP10K 分数。两者不能作为同一效应尺度比较。纠错运行未执行该结局族。
